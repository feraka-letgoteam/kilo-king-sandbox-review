# Kilo King v77 — God Mode and VS reconstruction

This is a new reconstruction from the saved v66 source, commit `147b96ea754a838dc878f503ec5db3593f607852`. It does not claim to restore the deleted v67–v76 source byte for byte. The supplied v73 video is an intermediate composition reference; the user's later corrections define the target.

## God Mode

The stopped board remains populated. A new opaque illustration the size of the complete reel window advances over it in literal fifth-window steps. The boat, seated driver, cockpit foreground and authored wake are separately rendered. Anticipation builds before each advance; hull pitch, upper-body counter-lean, wake pressure and braking end in stable poses. Only the recorded winning outcome aligns and stops the card in the complete frame. Early losses stall partially entered; the existing four-segment late-loss record produces an overshoot without a new random draw. An overshooting card never settles at the winning alignment.

The card owns its short illustrated MAX WIN or NO WIN impact. Amounts remain tabular text, and the existing transfer owns a winning credit once. Normal reel animation precedes the card; there is still one paid outcome. The old forced winning symbol row is removed, retaining the already-generated valid board with identical RNG consumption, binary outcome and payout.

## Yacht Stash / VS

Only contiguous reels with the same recorded side combine. A new neighbor expands a group; a bridging member joins matching runs. King never merges with Cop. Each group uses the product of its recorded members once. Distinct groups preserve the prior additive rule. New records are marked `adjacent-products-v77`; recovered `adjacent-products-v75` records are supported. Unmarked or unknown records retain legacy interpretation.

There are ten dedicated compositions, King and Cop at widths 1–5. Singles were refined to remove their painted lower fascia; wider compositions are independently painted, rather than stretched singles. Actual symbol strips are concealed under active and incoming VS units, including resize and merge. A finite anticipation/convergence/crossfade/product/settle sequence expands the art. Source Sans 3 Semibold 600 multipliers are warm white with a dark outline, without an added plaque or visible WILD caption. The existing connection clocks drive the number punch and transfer fade. Existing duel and award clocks remain unchanged; a new merge adds its documented finite presentation time.

## Protected systems

Wallet, settlement, prices, purchase flow, controls, reel geometry, collection, hook behavior, Chopper, Dockside and existing environment artwork/motion are retained. The only payout-rule change is the explicitly requested VS group multiplication. God Mode outcome probability and payout remain unchanged. Before-cap and credited values remain distinct.

## Run and verify

Use `npm ci`, `npm run dev:review` for the local review entry, `npm run test:kilo:features`, `npm run typecheck`, and `npm run build`. The v77 checks bundle an authenticated-by-hash snapshot of the exact v66 source/JSON baseline, so they run from a complete source ZIP without Git history. See `art/kilo-v77/v66-baseline-corrections.json` for two provisional working-copy hashes corrected from the immutable source commit.

Proofs execute the actual production stage and feature controllers using an instrumented Pixi runtime and native CPU Canvas painter. The WIN display is a minimal target harness. Clips are silent and are not browser/WebGL verification or screenshots of the complete React control UI. All captures carry a production source fingerprint.

The character and vessel use authored raster layers with controlled transforms and cockpit occlusion, not articulated 3D rigs or fluid simulation. Newly generated art is a reconstruction; prompts, originals, dimensions and hashes are retained under `art/kilo-v77/generated-*`. The build is saved without deployment.
