# Kilo King — control bar v19

These are **authored design frames, not browser screenshots**. Runtime browser QA is pending. All four use the same current layout and dock geometry:

- 360×800: `phone-small-360x800.png`
- 390×844: `phone-390x844.png`
- 844×390: `landscape-844x390.png`

The PNGs are standalone. SVGs reference the repository artwork. `index.html` provides a review gallery. `dock-study.png` isolates the current desktop/phone controls. `validation.json` records geometry, font and Auto scheduler checks. `manifest.json` records source art hashes and geometry.

See `CONTROL_BAR_V19_REVIEW.md` at the source root for checkpoint identity, test results, the pending browser acceptance matrix and limitations. Do not use these frames as evidence of live feature behavior or active resize.
